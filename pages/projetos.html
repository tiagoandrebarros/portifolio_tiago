Gerenciamento de pacientes e atendimentos em clinica odontológica

Projeto freelancer (ano: 2025)

Tipo: Programa desktop para Windows

O programa serve para fazer o cadastro de pacientes, cadastro de tratamentos que a clinica realiza, cadastrar os tratamentos a serem feitos em um paciente especifico e confirmar realização do tratamento informando o valor, medicações, dias de atestado e outras informações. Após o lançamentos dos dados relacionados aos atendimentos o programa pode gerar relatórios de ganhos e despesas de cada mês do ano selecionado

O programa também mantem um histórico dos tratamentos realizados por cada paciente separado de forma organizada, permitindo visualizar os atendimentos realizados de um paciente especifico.

Gerador de onda quadrada personalizavel

Projeto freelancer (ano: 2025)

Tipo: Microcontroladores e Mobile

Esse projeto consiste em usar um Arduino Nano para gerar uma onda quadrada que serve para acionar um dispositivo externo, as características da onda quadrada como frequências, duração de cada frequência e duty são enviadas de um smartphone para o Arduino Nano via bluetooth, dessa forma é possivel criar ondas quadradas personalizadas para fazer diferentes tipos de funcionamentos do dispositivo externo.

Nessa demostração a frequência gerada pelo Arduino estar sendo aplicada aos leds, no ambiente de produção os leds foram substituidos pelos equipamentos do cliente.

Sistema Web para testes de aceitação de alimentos

TCC de curso de graduação (ano: 2024)

Tipo: Sistema Web (Api Rest com Node.JS + SPA com React.JS + Banco de dados MongoDB

O sistema serve para automatizar alguns procedimentos repetitivos em testes de aceitação de alimentos. Durante a realização dos testes os provadores recebem amostras com os números de identificações codificados para que avaliem sem saber a composição do alimento para evitar influência psicológica, porem os números de identificações das amostras que cada provador recebe são diferentes mesmo sendo de alimentos iguais, com isso as amostras de um mesmo alimento recebe identificações diferentes que seguem um padrão de codificação, para que seja possível identificar a quais alimentos os números codificados estão associados.

Devido as características que foram citadas, um formulário padrão não pode ser usado e sem o sistema os pesquisadores precisão fazer a codificação e decodificação dos números manualmente, para poder armazenar os dados da forma correta em planilhas.

O sistema consegue automatizar a geração dos números codificados, fazer a coleta das respostas dos provadores por meio de um dispositivo mobile com um navegador de internet, decodificar a identificação das amostras que são enviadas pelos provadores, armazenar as respostas em banco de dados e gerar relatórios.
