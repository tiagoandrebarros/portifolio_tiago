Gerenciamento de pacientes e atendimentos em clinica odontológica.

Projeto freelancer (ano: 2025).

Tipo: Programa desktop para Windows.

O programa permite fazer o cadastro de tratamentos que a clinica realiza, cadastro de pacientes, registros de atendimentos, emissão de relatórios de atendimentos para o paciente selecionado entre outras funcionalidades.

Todo os dados ficam armazenados localmente na própria clinica, dessa forma o programa não depende de internet ou serviços externos para funcionar.

O Programa é multiusuário e possui dois tipos:

  • Usuário comum: pode haver vários, responsáveis por registrar os atendimentos realizados.
  • Usuário administrador: único, com acesso para gerenciar o cadastro dos usuários comuns e consultar relatórios financeiros da clínica.

Plataforma giratória sincronizada com acionamento de câmera.

Projeto freelancer (ano: 2025).

Tipo: Microcontroladores.

O software serve para tirar fotos em ângulos diferentes, usando um Arduino com um motor de passo para girar a plataforma. O usuário informa a quantidade de fotos desejada o Arduino calcula onde serão os ângulos para cada foto e controla o giro da plataforma por um motor de passo, quando chega o momento de tirar a foto ele para a plataforma e envia o sinal de acionamento para a câmera.

Fiz a programação do Arduino e o esquema elétrico, a parte estrutural da plataforma foi feita pelo cliente.

Sistema Web para testes de aceitação de alimentos.

TCC de curso de graduação (ano: 2024).

Tipo: Sistema Web (Api Rest com Node.JS + SPA com React.JS + Banco de dados MongoDB).

O sistema serve para automatizar alguns procedimentos repetitivos em testes de aceitação de alimentos. Durante a realização dos testes os provadores recebem amostras com os números de identificações codificados para que avaliem sem saber a composição do alimento, evitando a influência psicológica, porem os números de identificações das amostras que cada provador recebe são diferentes mesmo sendo de alimentos iguais, com isso as amostras de um mesmo alimento recebe identificações diferentes que seguem um padrão de codificação, para que seja possível identificar a quais alimentos os números codificados estão associados.

Devido as características que foram citadas, um formulário padrão não pode ser usado e sem o sistema os pesquisadores precisão fazer a codificação e decodificação dos números manualmente, para poder armazenar os dados da forma correta em planilhas.

O sistema consegue automatizar a geração dos números codificados, fazer a coleta das respostas dos provadores por meio de um dispositivo mobile com um navegador de internet, decodificar a identificação das amostras que são enviadas pelos provadores, armazenar as respostas em banco de dados e gerar relatórios.
